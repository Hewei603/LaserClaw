# 激光安全操作规程 (SOP)
# [SAMPLE DATA — 示例数据，非真实实验室文件]

## 1. 适用范围

本规程适用于实验室内所有激光设备的操作，包括 Nd:YAG、Ti:Sapphire、CO2 等固体和气体激光器。

## 2. 激光危害等级

| 等级 | 描述 | 典型功率 |
|------|------|---------|
| Class 1 | 安全，无危害 | < 0.39 mW |
| Class 2 | 可见光，眨眼反射保护 | < 1 mW |
| Class 3R | 低风险，直视危险 | < 5 mW |
| Class 3B | 直视危险，漫反射安全 | 5–500 mW |
| Class 4 | 直视和漫反射均危险，可引燃 | > 500 mW |

## 3. 个人防护装备 (PPE)

- **激光防护眼镜**：必须与激光波长和光密度 (OD) 匹配
  - 1064 nm Nd:YAG：使用 OD ≥ 4 的 1064nm 防护镜
  - 532 nm 倍频：使用 OD ≥ 4 的 532nm 防护镜
  - 不得使用普通太阳镜替代
- **防护手套**：处理光学元件时佩戴无尘手套
- **实验服**：穿着阻燃实验服

## 4. 实验室安全要求

### 4.1 进入控制
- 激光运行时，门口必须张贴激光警告标志
- 非授权人员不得进入激光操作区域
- 访客必须佩戴适当防护眼镜

### 4.2 光束控制
- 光束路径必须在光学台面高度，避免与眼睛等高
- 使用光束挡板 (beam dump) 终止不需要的光束
- 禁止将光束指向人员或反射面
- 光束路径周围不得有不必要的反射物

### 4.3 电气安全
- 高压电源操作前必须断电并等待放电
- 不得单独操作高压设备
- 定期检查电缆绝缘状态

## 5. 紧急程序

### 5.1 眼部受伤
1. 立即关闭激光
2. 不要揉眼睛
3. 立即就医，告知激光波长和功率
4. 记录事故经过

### 5.2 皮肤灼伤
1. 立即关闭激光
2. 用冷水冲洗 15 分钟
3. 就医处理

### 5.3 火灾
1. 立即关闭激光和电源
2. 使用 CO2 灭火器（不得用水）
3. 疏散人员，拨打 119

## 6. 操作前检查清单

- [ ] 确认防护眼镜佩戴正确
- [ ] 检查光束路径无障碍物
- [ ] 确认光束挡板就位
- [ ] 检查冷却水流量（水冷激光器）
- [ ] 确认激光警告标志已张贴
- [ ] 通知实验室其他人员

## 7. 功率计使用

- 使用前预热 5 分钟
- 选择合适量程，避免过载
- 探头放置在光束中心
- 记录读数时等待稳定（通常 10–30 秒）
