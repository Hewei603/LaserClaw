# Nd:YAG 和 LBO 晶体简介
# [SAMPLE DATA — 示例数据，非真实实验室文件]

## 1. Nd:YAG 激光晶体

### 1.1 基本参数
- **化学式**：Nd³⁺:Y₃Al₅O₁₂（钕掺杂钇铝石榴石）
- **典型掺杂浓度**：0.5%–1.5% at.%
- **基频波长**：1064 nm（主线），1319 nm，946 nm
- **荧光寿命**：~230 μs
- **热导率**：14 W/(m·K)（较高，适合高功率）
- **折射率**：1.82 @ 1064 nm

### 1.2 泵浦方式
- **灯泵浦**：氙灯或氪灯，效率较低（1–3%）
- **二极管泵浦（LD）**：808 nm 吸收峰，效率高（10–20%）
  - 端面泵浦：适合低功率，光束质量好
  - 侧面泵浦：适合高功率，热管理好

### 1.3 工作模式
- **CW（连续波）**：稳定输出，适合精密测量
- **Q-switched（调Q）**：纳秒脉冲，峰值功率高
- **Mode-locked（锁模）**：皮秒/飞秒脉冲

### 1.4 常见问题
- **热透镜效应**：高功率时晶体温度梯度导致折射率变化，影响光束质量
- **ASE（放大自发辐射）**：高增益时降低效率
- **双折射**：热应力导致偏振态变化

## 2. LBO（三硼酸锂）非线性晶体

### 2.1 基本参数
- **化学式**：LiB₃O₅
- **透过范围**：160 nm–2600 nm
- **非线性系数**：d₃₂ = 1.05 pm/V（较低，但损伤阈值高）
- **损伤阈值**：> 25 GW/cm²（1064 nm，10 ns 脉冲）
- **双折射类型**：负双轴晶体

### 2.2 倍频（SHG）应用
- **1064 nm → 532 nm**（Nd:YAG 倍频，绿光）
  - I 类相位匹配：θ = 90°，φ = 11.4°（非临界相位匹配，NCPM）
  - 温度调谐：约 0.5°C/nm
  - 典型转换效率：40–60%（腔内倍频）

### 2.3 相位匹配条件
- **临界相位匹配（CPM）**：通过角度调谐
- **非临界相位匹配（NCPM）**：通过温度调谐，走离角为零，效率更高
- 对于 1064→532 nm，NCPM 温度约为 148°C

### 2.4 使用注意事项
- LBO 有轻微吸湿性，长期存储需防潮
- 高功率使用时需要温控（±0.1°C 精度）
- 端面镀增透膜（AR coating）减少菲涅耳损耗
- 避免机械应力，安装时使用柔性夹持

### 2.5 与 KTP 对比

| 参数 | LBO | KTP |
|------|-----|-----|
| 损伤阈值 | 高（>25 GW/cm²）| 中（~1 GW/cm²）|
| 非线性系数 | 低（1.05 pm/V）| 高（3.4 pm/V）|
| 吸湿性 | 轻微 | 无 |
| 适用功率 | 高功率 | 中低功率 |
| 典型应用 | 高功率倍频 | 低功率倍频 |
