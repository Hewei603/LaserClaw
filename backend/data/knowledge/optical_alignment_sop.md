# 光路准直操作规程 (SOP)
# [SAMPLE DATA — 示例数据，非真实实验室文件]

## 1. 准直前准备

### 1.1 工具清单
- 激光功率计（预热 5 分钟）
- 光阑（iris diaphragm）× 2
- 白屏或荧光屏
- 六维调整架扳手
- 激光防护眼镜（匹配波长）

### 1.2 安全检查
- 佩戴防护眼镜
- 确认光束挡板就位
- 通知实验室其他人员

## 2. 基本准直方法

### 2.1 两光阑法（推荐）

1. 在光路起点和终点各放置一个光阑
2. 调整光阑高度至目标光束高度（通常为光学台面以上 100mm）
3. 调整激光器或第一个反射镜，使光束通过近端光阑
4. 调整第二个反射镜，使光束通过远端光阑
5. 重复步骤 3–4，直到光束同时通过两个光阑

### 2.2 迭代准直步骤

对于多镜面光路：
1. 从激光器出口开始，逐段准直
2. 每段使用两光阑法
3. 确认每段准直后再进行下一段
4. 最终检查：光束从头到尾通过所有光阑

## 3. 腔内准直

### 3.1 线形腔准直
1. 移除增益介质，使用低功率导引激光
2. 调整 HR 镜使反射光与入射光重合
3. 放入增益介质，调整位置使光束通过晶体中心
4. 调整 OC 镜，观察腔内模式
5. 微调 HR 和 OC，优化输出功率

### 3.2 常见问题
- **光斑不圆**：检查晶体是否倾斜，调整晶体角度
- **输出功率低**：检查腔镜反射率，确认准直精度
- **模式不稳定**：检查腔长是否在稳区内

## 4. 准直质量评估

| 指标 | 合格标准 |
|------|---------|
| 光束位置重复性 | < 0.1 mm |
| 光束角度偏差 | < 1 mrad |
| 通过光阑透过率 | > 95% |
| 输出功率稳定性 | < 2% RMS |

## 5. 记录要求

准直完成后记录：
- 准直日期和操作人员
- 各光阑位置坐标
- 输出功率读数
- 光束质量（M² 如有条件测量）
