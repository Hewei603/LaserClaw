# 功率计使用说明
# [SAMPLE DATA — 示例数据，非真实实验室文件]

## 1. 仪器概述

功率计用于测量连续波 (CW) 和脉冲激光的平均功率。常见型号包括 Thorlabs PM100D、Newport 843-R 等。

## 2. 探头选择

| 探头类型 | 适用波长 | 功率范围 | 特点 |
|---------|---------|---------|------|
| 热电堆 | 190nm–20μm | 10μW–150W | 宽波段，响应慢 |
| 光电二极管 | 200nm–1100nm | 1nW–100mW | 响应快，灵敏度高 |
| 热释电 | 脉冲激光 | 1μJ–100mJ | 适合脉冲测量 |

## 3. 操作步骤

### 3.1 开机预热
1. 连接探头到主机
2. 开机，等待 5 分钟预热
3. 选择正确波长（影响响应率校正）
4. 选择合适量程（避免过载）

### 3.2 测量步骤
1. 将探头放置在光束路径中，探头面垂直于光束
2. 确认光束完全落在探头有效面积内
3. 等待读数稳定（CW 激光通常 10–30 秒）
4. 记录读数，注意单位（W 或 mW）

### 3.3 注意事项
- **不要超过探头最大功率**：过载会损坏探头
- **避免直流背景光**：关闭室内灯或遮挡环境光
- **探头清洁**：用无尘布轻轻擦拭，不要用手触摸
- **热电堆探头**：测量前确认探头温度稳定

## 4. 常见问题排查

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 读数不稳定 | 激光不稳定或环境振动 | 检查激光源，隔振 |
| 读数偏低 | 光束未完全打在探头上 | 调整探头位置 |
| 读数为零 | 量程选择错误或探头损坏 | 检查量程，更换探头 |
| 过载报警 | 功率超过量程 | 降低功率或换大量程探头 |

## 5. 校准

- 功率计应每年送检校准一次
- 使用前检查校准证书有效期
- 记录每次测量时的校准状态
